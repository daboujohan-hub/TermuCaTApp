# TermChat

Messagerie chiffrée par AbouDev Labs (DEV.D.A.J) — Côte d'Ivoire, Sénégal, Guinée, Burkina Faso, Ghana, Mali, Togo, Bénin, Niger, Nigeria, Cameroun.

## Fonctionnalités
- Messages chiffrés de bout en bout (quand le contact a une clé)
- Messages vocaux
- Profil : photo, bio, statut, couleur
- Blocage et signalement d'un utilisateur
- Double authentification (2FA) et code PIN de verrouillage
- Notifications
- EduMap : carte et liste des écoles

## Installer (Android)
1. Ouvre la page **Releases** et télécharge le fichier `.apk` de la dernière version.
2. Si Android le demande, autorise ton navigateur à **installer des applications inconnues**.
3. Ouvre le fichier et installe. Play Protect peut afficher un avertissement : c'est normal, l'application n'est pas sur le Play Store.
4. Les mises à jour ne sont pas automatiques : télécharge la nouvelle version depuis **Releases** et installe-la par-dessus.

## Vérifier le fichier
Le code SHA-256 de chaque version est indiqué dans sa description. Pour le comparer :
`sha256sum TermChat-X.Y.Z.apk`
